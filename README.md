# python-calculator
A simple calculator built in Python with a loop and input validation
This is a basic calculator code written in python language
Functionalities:
               4.1 It can perform the "+","-","/","*" operations
               4.2 In case of operator other than that the program show a message saying Invalid operator
               4.3 In case of someone write the num1 & num2 in alphabets or like 90/ the program stop and show saying that                    Enter a valid number as this one is invalid.  It is because of using Try/except code.
               4.4 In case of "/" operation the program will first check that if num==0 it will say the denominator can't be                  zero. 
               4.5 While loop is used in this program which allow the user to keep performing calculation as they are giving                  the input as Yes.
               4.6 It can accept the input as Yes,yes,YES,yEs because with condition the lower() method is used.
               4.7 It also accepts space before and after yes because strip() method is used.
